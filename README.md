# ВАВИЛОНСКАЯ БИБЛИОТЕКА
В данном проекте обкатываются механики генерации процедурной карты на основе графов.

# Узлы
Набор узлов сокращён для простоты тестирования и сведён к 2м локациям.

# Структура проекта
## Ветка feature_gen_* 
Ветка feature_gen_by_chunk отвечает за эксперимент по итеративной генерации гексагонального графа.
Ветка feature_gen_\[УДАЛЕНО] отвечает за \[УДАЛЕНО].
Ветка feature_gen_\[УДАЛЕНО] отвечает за \[УДАЛЕНО].

## Века getBook
Прикладная ветка ля интерактивного тестирования метода █████████. Удалена из за смены приоритета внедрения системы.

## Ветка total_rework
Эта ветка отвечает за переход к новому подходу, для генерации основанном на указаниях системы правил
